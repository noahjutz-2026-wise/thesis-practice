# MuJoCo Sysid

## Quickstart

```bash
uv run python -m mujoco_sysid.broker
uv run python -m mujoco_sysid.camera
uv run python -m mujoco_sysid.estimator
uv run python -m mujoco_sysid.debugger # optional: estimation outputs
uv run python -m mujoco_sysid.actuator
uv run python -m mujoco_sysid.manual # optional: manual inputs
```
